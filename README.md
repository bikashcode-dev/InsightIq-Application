# 📖 Overview

**InsightIQ** is an AI-powered Business Intelligence and Sales Analytics platform that transforms massive sales datasets into actionable business insights.

Instead of manually analyzing spreadsheets containing thousands or even millions of records, users simply upload a CSV file, and InsightIQ automatically performs intelligent sales analysis, generates business insights, creates interactive dashboards, and answers business questions using AI.

The platform combines the power of **Spring Boot**, **Spring AI**, **Ollama**, **MySQL**, and **Python Visualization** to deliver a complete AI-driven analytics solution.

---

# 🎯 Problem Statement

Businesses often store years of sales data in spreadsheets or databases, but extracting meaningful insights requires technical knowledge, SQL expertise, and significant manual effort.

Managers frequently ask questions like:

* Which product sells the most?
* Which products generate the highest profit?
* Which products are underperforming?
* Which categories are trending?
* What caused revenue to decrease?
* Which inventory should be restocked?
* Which products should be discontinued?

Traditional dashboards only display charts—they don't explain the business.

**InsightIQ acts like an experienced Sales Manager and Business Analyst, helping decision-makers understand their data instead of just viewing it.**

# 🧠 Natural Language → SQL Engine

InsightIQ automatically converts user questions into optimized SQL queries using **Spring AI + Ollama**.

### Workflow

```text
User Question
      │
      ▼
Spring AI + Ollama
      │
      ▼
Generate SQL Query
      │
      ▼
SQL Validation Layer
      │
      ▼
Execute Query
      │
      ▼
Analyze Results
      │
      ▼
Generate Business Insights
      │
      ▼
Python Visualization
      │
      ▼
Interactive Dashboard
```

### SQL Safety Layer

Only safe read operations are allowed.

Blocked Queries:

* DELETE
* DROP
* UPDATE
* ALTER
* TRUNCATE
* INSERT

Only validated **SELECT** queries are executed.
